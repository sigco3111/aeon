## 🌟 게임 소개

AEON은 **신 게임**(WorldBox 류)과 **문명 시뮬레이터**(Civ 류)를 하나로 합친 브라우저 게임입니다.
여기에 결정적인 한 가지를 더합니다 — **모든 생물이 진짜 진화하는 신경망을 가집니다**.

```
┌─────────────────────────────────────────────────────────┐
│  🧠  각 생물은 고정 위상 MLP 한 개를 뇌로 가집니다       │
│  🧬  유전자가 돌연변이/교배를 거치며 행동이 진화합니다      │
│  🌾  선택 압력이 그들에겐 진짜로 작용합니다               │
│  👑  시민은 누가 누군지, 어떻게 행동할지 스스로 결정합니다  │
│  ⚔  국가를 이끄는 신은 법을 정하고, 결정은 시민의 뇌가    │
└─────────────────────────────────────────────────────────┘
```

누군가 미리 정해둔 대사를 따라하는 NPC는 없습니다. 그들은 진짜로 **배우며**, 진짜로 **적응하고**, 진짜로 **갈등**합니다.

## 🎯 두 가지 플레이 방식

### 서바이벌 — *Civ처럼*

한 민족을 직접 만듭니다:

1. **이름** — `Aurelian Kin`, `바다의 아우렐리안`, …
2. **깃발 색** — 12가지 색조 중 선택
3. **유산** — 최대 2가지 (강인함 / 다산 / 무인 / 학자 / 날쌘함 / 녹음의 백성 / 바다의 백성)

그리고 그 민족을 라이벌들이 일어서는 살아있는 세계로 이끕니다:

| 행동 | 설명 |
|------|------|
| **정책 슬라이더** | 전쟁 / 확장 / 번식 / 학문을 -1.0 ~ +1.0로 조정 |
| **연구 우선 과제** | 다음에 어떤 기술을 탐구할지 지정 |
| **외교** | 라이벌과 동맹/전쟁/평화/교역 |
| **도시 세우기** | (금화 10) 비옥한 땅에 캠프 → 촌락 → 마을 → 도시 |
| **숙원** | 장기 승리 목표 선택 (200인 / 정보 시대 / 패권 / 신앙 전파 / 도시 3개 / 만민 동맹 / 300년) |
| **승천** | 신 시점으로 돌아가거나 그냥 관찰 — 평의회가 당신의 뜻대로 이끕니다 |

**승리도 패배도 명확합니다.** 살아남으면 이기고, 0명이 되면 끝입니다.

### 크리에이티브 — *WorldBox처럼*

신의 손 — 신이 되어 세계를 빚습니다:

| 도구 | 단축키 | 효과 |
|------|--------|------|
| 🔍 **조사** | I | 생물/도시/민족을 클릭해 그 이야기를 확인 |
| ⛰ **땅 올리기** | R | 드래그로 산/구릉/육지 다리를 만듭니다 |
| 🌊 **내리기/물** | L | 드래그로 호수/강/바다를 팝니다 |
| 🌲 **숲** | F | 수집인의 먹이가 되는 나무/풀을 자라게 합니다 |
| ✿ **생명 창조** | S | 클릭한 자리에 진화하는 마음을 가진 새 부족을 심습니다 |
| 🍒 **음식 축복** | B | 고군분투하는 민족을 위해 식량을 뿌립니다 |
| ⚡ **내리침** | X | 직경 안의 모든 것을 내리칩니다 — 자연 선택 |
| 👁 **빙의** | P | 한 몸에 내려타서 WASD로 직접 걸어봅니다 |

**목표는 없습니다.** 빚고, 문명이 스스로 오르내리는 것을 지켜보세요.

## ⚙️ 실제로 시뮬레이션되는 것들

### 🧠 진짜 진화하는 뇌

- 각 생물은 **고정 위상 MLP**(`N_IN → N_HID → N_OUT`) 한 개를 뇌로 가집니다.
- 유전자가 돌연변이와 교배를 거치며 행동 패턴이 진화합니다.
- **체구 / 속도 / 신진대사 / 출산력 / 공격성 / 시각 / 식성 / 회복력** 8가지 형질이 유전되며 시각적으로 보입니다.
- 살아있는 생물을 클릭하면 **뇌가 시각화**됩니다 — 흥분 노드(파란색)와 억제 노드(빨간색), 그리고 그 사이의 시냅스 가중치.

### 🍞 욕구와 환경

- **배고픔 / 갈증** — 물가에 정착하지 않으면 멸망.
- 자원이 **고갈**되거나 **재생성**됩니다 — 숲은 천천히 다시 자라고, 강철은 유한합니다.
- 동물이 **먹이사슬**을 형성합니다 — 사냥감과 포식자가 인간과 함께 살아갑니다.

### 🏗️ 경제 시스템

- **목재 / 돌 / 광석** 노드에서 자원을 채굴합니다.
- 자원 가공: **돌 도구** → **청동 도구** → **철 도구** → **강철 도구**
- 도시의 초점을 **🌱 성장 / 🏛 건축 / ⚔ 군사 / 🪙 금화 / 🔬 연구** 중에서 선택합니다.
- 노드는 채굴 속도와 종류가 다르며, **지역 자원 분포**가 균등하지 않습니다 — 어떤 민족은 광석이 풍부하고, 어떤 민족은 목재가 풍부합니다. 그래서 **교역이 일어납니다**.

### 📚 기술 트리 (24개, 9시대)

`석기 시대` → `청동기 시대` → `철기 시대` → `고전 시대` → `중세 시대` → `르네상스` → `산업 시대` → `근대 시대` → `정보 시대`

| 시대 | 기술 |
|------|------|
| **석기 시대** | 🔥 불 · 🪨 석기 · 🌾 농업 · 🐂 목축 · 🍶 토기 |
| **청동기 시대** | 🎡 바퀴 · ✍️ 문자 · 🔨 청동 제작 · ⛵ 항해 |
| **철기 시대** | 🔢 수학 · 💰 화폐 · ⚒ 철 제작 · 🏛 석조 |
| **고전 시대** | 🏗 공학 · 💊 의술 |
| **중세 시대** | 🧭 나침반 · 💥 화약 |
| **르네상스** | 📰 인쇄술 · 🔬 과학적 방법 |
| **산업 시대** | 🚂 증기 기관 · ⚡ 전기 · 🏭 공업화 |
| **근대 시대** | 🚗 내연 기관 · 🧪 플라스틱 · ✈️ 유인 비행 |
| **정보 시대** | 💻 컴퓨팅 |

**자물쇠-열쇠 메커니즘**: `Sailing`이 없으면 보트를 못 만들고, `Flight`가 없으면 비행이 불가능합니다.

### 🏛️ 시민 제도 트리 (14개, 7정부)

`친족` → `구전 전통 / 관습과 의례` → `전사의 도리 / 동맹 결성` → `법전 / 신비주의` → `철학 / 길드` → `시민권 / 봉건제` → `계몽주의` → `민족주의 / 민주주의`

| 시민 제도 | 확립하는 정치 체제 |
|----------|------------------|
| **친족** | 추장부 |
| **동맹 결성** | 동맹 |
| **법전** | 군주국 |
| **신비주의** | 신정정치 |
| **시민권** | 공화국 |
| **민족주의** | 전제정치 |
| **민주주의** | 민주주의 |

### 🏘️ 정착지 성장

**캠프 → 촌락 → 마을 → 도시** — 인구에 따라 자동 성장, 시대가 높을수록 더 큰 단계로 도달할 수 있습니다.

### 🗺️ 영토와 국경

- 도시는 시간이 지나며 주변을 **자연스럽게 확장**합니다.
- **금화**를 써서 더 빠르게 주장할 수 있습니다.
- 지키지 못하는 땅은 **라이벌이 정복**합니다 — 이벤트가 발생하고 토스트에 알림이 뜹니다.

### ⚔️ 전투와 유닛

- 시민 / **전사(근접)** / **원거리병** 세 가지 역할
- 병사 수는 **공격성 정책**으로 결정
- 무기는 **금속 비축량**에 따라 강해짐

### 🤝 외교

- 4가지 자세: **동맹 / 중립 / 적대 / 전쟁**
- **불만(grievance)** 시스템 — 시간이 지나면서 옅어지지만, 배신은 오래 기억됩니다.
- AI 민족도 **동일한 GovernanceAPI**를 사용합니다 — 인간과 AI의 외교는 투명하게 동일한 규칙을 따릅니다.

### 🏺 민족학

각 민족은 시간이 지나며 **민족 기풍(ethos)** 을 발전시킵니다:

- ⚔️ **무장사회** — 전사식 의례
- 🤝 **공동체** — 친족 명절과 함께하는 화덕
- 🛐 **경건** — 조상숭배와 거룩한 날
- 🔨 **근면** — 길드 도제 제도
- 📚 **학예** — 구전 역사와 별의 비밀
- 🏕 **유랑민** — 계절에 따른 이동

민족 기풍은 어떻게 살고 있는지를 **읽고** 자동으로 결정됩니다 — 스크립트가 아닙니다.

### 🦌 야생 동물

- **사슴(먹이)** — 가죽, 고기, 가끔 약초
- **늑대(포식자)** — 모피, 송곳니(뼈), 고기
- 두 종류 모두 인간과 함께 살아가는 세계의 일부입니다.

### 🌍 숨 쉬는 세계

낮과 밤, 계절에 따른 날씨, 빛나는 물, 흘러가는 구름, 굴뚝 연기, 걸어 다니고 짐을 나르고 숨 쉬는 생물들.

## 🚀 직접 실행하기

AEON은 **빌드 단계가 없고, 의존성이 없습니다.** ES Module만 사용하므로 어떤 정적 서버로도 띄울 수 있습니다.

### 옵션 1: 저장소 내 서버 사용

```bash
git clone https://github.com/lordbasilaiassistant-sudo/aeon.git
cd aeon
node serve.mjs        # → http://localhost:8123
```

### 옵션 2: 다른 정적 서버

```bash
# Python 3
python3 -m http.server 8123

# 또는 npx
npx serve
```

> ⚠️ **file:// 로 직접 열지 마세요** — ES Module은 HTTP 환경이 필요합니다.

### 헤드리스 통합 테스트

```bash
npm test              # → node test/headless.mjs
```

브라우저 없이 시뮬레이션을 돌려 "생명이 살아남고 진화한다"는 불변식을 검증합니다.
**GitHub Actions**가 모든 푸시마다 동일 체크를 실행합니다.

│   ├── territory.js      — 영토 주장/잃기

## 📊 상태 & 로드맵

AEON은 **초기 단계**이며 활발히 개발 중입니다 — 시뮬레이션은 동작하지만 *게임* 자체는 아직 만들어가는 중입니다.

### 2026-06-13 기준 착지한 것 (Sprint 1)

- ✅ **도시 세우기가 도달 가능** — 국가가 도시 비용을 모을 만큼 금화를 비축하며, 거부된 타일은 *이유* (너무 가까움 / 물 / 점유됨)를 설명해줍니다.
- ✅ **지시된 보병 유닛이 길찾기를 완료** — 흐름장(flow-field)이 물과 산을 우회합니다.
- ✅ **~29× 빠른 렌더링** — 뷰포트 컬링, LOD, DPR 거버너가 프레임을 ~34ms → ~1ms로 줄였습니다.

### 현재 알려진 한계 (GitHub 이슈로 추적)

- 🚧 **플레이어 국가가 수동적으로 쇠퇴** + **승리/패배 화면 부재** — 핵심 서바이벌 루프와 fail-state가 헤드라인 갭 (#8, P0).
- 🚧 **긴 행군이 실제 플레이에서 끝나지 않음** — 보병이 행군 중 채집/휴식을 하지 않습니다 (#8, #3).
- 🚧 **지휘/도시 모드의 발견성 부족** — 조용한 토글로 배너/커서 큐가 없습니다 (#5).

### 설계된, 아직 만들지 않은 방향

- 🔮 **더 깊은 경제** — 행동이 화폐를 소비하고, 세워진 도시는 계속되는 필요가 있습니다 (#6, `ECONOMY_DESIGN.md`).
- 🔮 **살아있는 시민 ("Free Guy" 원칙)** — 감정, 배고픔, 공동체, 그리고 생존 동기가 아닌 개인적 행동 (#7, `AGENT_LIFE_DESIGN.md`).
- 🔮 **진짜 3D WebGL2 렌더러** — 방향은 잠겨 있고 로컬 스파이크가 있지만, 아직 연결되거나 출시되지는 않았습니다 (#9, `GRAPHICS_3D_DESIGN.md`).

GitHub Actions는 모든 푸시마다 헤드리스 불변식을 실행합니다. 모든 작업은 `SPRINT_PLAN.md`에 따라 GitHub 이슈(#1–#9)로 추적됩니다.

## 🌏 한글화 노트

### 이 저장소의 한글화 방식

이 저장소는 한글화 **포트**입니다 (`lordbasilaiassistant-sudo/aeon`의 한글판).

**표시되는 모든 사용자 인터페이스 텍스트는 한국어**입니다 — 시작 화면, 메뉴, HUD, 인스펙터, 튜토리얼, 시스템 메시지, 토스트, 종결 화면, 도움말, 정책 슬라이더, 기술 트리, 시민 제도 트리, 유산, 아이템 이름, 민족 기풍, 숙원.

### 보존된 것

- **식별자** — `id`, `key`, `tech`, `prereqs`, `kind`, `value`, `effect` 같은 모든 내부 키는 영문 그대로입니다. (`Fire`, `kinship`, `martial`, `Growth`, `wood`, `smithy` 등)
- **외부 API** — `setPolicy('aggression', 0.5)`, `setStance(a, b, 'war')` 같은 호출 시그니처는 동일하게 작동합니다.
- **단축키** — `I`, `R`, `L`, `F`, `S`, `B`, `X`, `P`, `Space`, `1–5` 그대로.

### 변경된 것

- 표시 텍스트 (이름, 설명, 도움말, 토스트, 인스펙터 라벨) → 한국어
- 시작 화면, 모달, 튜토리얼, 메뉴, 종결 화면 → 한국어
- 메타데이터 (HTML title/description/keywords, Open Graph, schema.org) → 한국어
- 시뮬레이션 emit 메시지 (예: `${tr.name}이(가) ${td.name} 기술을 발견합니다`) → 한국어

### 검증된 것

- **17/18 핵심 모듈**이 ES Module로 정상 import (main.js는 document 부재로 node 환경에서 실패 — 브라우저 전용)
- **시뮬레이션 60년 실행** 시 emit 메시지의 **87.5%가 한글** (나머지 영문은 자동 후처리로 한글로 변환됨)
- **식별자 침투 0건** — Fire/Chiefdom 같은 영문 enum이 UI에 노출되는 일 없음
